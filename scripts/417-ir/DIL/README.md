# 任务说明

在域增量任务上，需要重点关注：
1. 各阶段模型分别在各个数据集上的mAP50评估结果
2. 各阶段的训练时间（以小时为单位，只计算从最初 epoch 到 best checkpoint 产生的时间）
以上所涉及的 mAP 都是在 task-agnostic 协议下评估的

需要分别基于 naive 和 espreg+replay 两种方法组合进行实验
对于模型在各阶段数据集的评估结果矩阵，需要抽取出另一个记录方式，按照如下命名方式：
“[一阶段训练类别]训练 + [二阶段训练类别]微调/增量 + [三阶段训练类别]微调/增量 + ...”
其中各阶段训练类别之间用“、”连接，“微调”和“增量”分别指 naive 和 espreg+replay 两种方法组合

对于第 k 个阶段（k >= 2），统计以下三项：
1. 前 (k-1) 个阶段按顺序微调的结果
2. 前 k 个阶段按顺序微调的结果
3. 前 k 个阶段按顺序在增量模块下训练的结果
每个统计项展示前 k 个任务数据集上的全部评估结果，以及各阶段训练时长，形成如下格式的表格
|记录项|任务1评估结果|…|任务k评估结果|各阶段训练时长|

其中训练时长以“[一阶段训练时长]+[二阶段训练时长]+…”的格式记录

# 任务说明

在类增量任务上，需要做多种设置的实验。该目录下每个子目录代表一种实验设置。

每个实验设置需要重点关注：
1. 旧类别（航母+驱逐舰）的 mAP50
2. 新类别（黄蜂）的 mAP50
3. 各阶段的训练时间（以小时为单位，只计算从最初 epoch 到 best checkpoint 产生的时间）

以上所涉及的 mAP 都是在 task-agnostic 协议下评估的

对于每个实验设置，需要分别基于 naive 和 pseudo_label+espreg+replay 两种方法组合进行实验，其中 naive
对于实验结果的记录，按照如下命名方式：
“[一阶段训练类别]训练 + [二阶段训练类别]微调/增量”

每个实验结果的评估结果应当汇总成如下表格的一行：
|结果记录名称|一阶段评估结果|二阶段评估结果|各阶段训练时长|

其中训练时长以“[一阶段训练时长]+[二阶段训练时长]”的格式记录

其中各阶段训练类别之间用“、”连接，“微调”和“增量”分别指 naive 和 pseudo_label+espreg+replay 两种方法组合
而对于“-400”，则表示该数据集是随机抽取的少样本数据集，在后面加上“（少样本）”标注
对于“-pruned-400”表示该少样本集是通过数据剪枝算法抽取的，在后面加上“（最优样本）”标志

举例说明：
`METHOD=pseudo_label+espreg+replay bash myultralytics/scripts/417-ir/CIL/bk+hm->hf-pruned-400/pipeline.sh` 对应的结果记为
“驱逐舰、航母训练+两栖（最优样本）增量”

除了各子目录对应的实验组别，还有一个额外的评估组别是：“驱逐舰、航母训练（在两栖数据集上按照objectness评估）”

feat: Add YOLOFiLM model with CLIP-based attribute encoding

Implement YOLOFiLM, a conditional object detection model that integrates
FiLM (Feature-wise Linear Modulation) mechanism with CLIP-based text
encoding for attribute-aware detection.

## Core Features

### YOLOFiLM Model
- DetectionModelFiLM: Extends DetectionModel with FiLM modules
- AttributeEncoder: Uses CLIP ViT-B/32 pretrained weights for text encoding
- FiLM modules: Feature-wise linear modulation at detection head inputs
- Multi-scale modulation: Independent FiLM modules for P3, P4, P5 scales

### Data Pipeline
- JSONAttributeDataset: Custom dataset class for JSON-formatted annotations
- Natural language attribute conversion: Structured attributes → text descriptions
- Attribute text collation: Proper handling in data loading pipeline

### Training & Validation
- FiLMTrainer: Custom trainer with attribute text support
- FiLMValidator: Validator with JSON dataset and attribute text handling
- YOLOFiLM interface: Unified model interface with task mapping

### Tools
- convert_yolo_to_json.py: Convert YOLO format to JSON with attributes
- train_yolo_film.py: Training script example

## Technical Highlights

1. CLIP Integration
   - Uses CLIP ViT-B/32 pretrained weights (frozen)
   - Trainable projection layer maps CLIP features to target dimension
   - Automatic device management and gradient flow

2. FiLM Mechanism
   - Scale and shift modulation: output = input * gamma + beta
   - Per-channel modulation parameters
   - Initialization: scale starts at 1.0, shift at 0.0

3. Flexible Attribute Format
   - Supports arbitrary structured attribute dictionaries
   - Automatic conversion to natural language text
   - Default handling for missing attributes
